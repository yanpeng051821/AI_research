# 固定随机样本编码预检

> 2026-10-30。对已固定的 1,000 条随机样本完成训练前编码诊断，未发现本入口所查的编码标记。不代表质量接受、全量预检或数据配方冻结。

## 1. 目的与实现

此前 Dataset 可在取样时触发校验，但正式训练不能靠遍历到某条记录才首次发现问题。本次新增独立入口 [inspect_sft_encoding.py](../../../implementation/scripts/inspect_sft_encoding.py)，在不构造 DataLoader、不加载模型、不执行工具的情况下，对原始样本包进行编码预检。

入口先核对样本文件与既有结构报告记录的 SHA256，再逐条执行基础 validator、字段转换与同一套 `encode_sft_conversation`。适配后的消息和工具声明中出现 BOS/EOS 字面标记时，记录为潜在边界风险；编码后检查 input_ids 与 labels 等长，按 labels[1:] 统计有效目标。结构错误、字段转换错误、模板/编码错误、潜在边界标记与零目标分别计数。

边界扫描是保守提示，不是完整消息解析证明，也没有修复训练编码器中的伪边界问题。零目标检查属于本预检入口，不表示 Dataset 或训练循环已经加上相同门禁。编码长度统计保留所有成功编码记录，包括可能带诊断标记的记录；不把统计对象称为已接受训练集。

## 2. 输入与复跑

输入来自 seed=20261029 的全体均匀蓄水池随机样本，不是文件前缀，也不是三类各 16 条的分组观察样例。其 SHA256 为 `6d5afb5706ac7e2f68c4f32448dba5f88802a55ce513fa7117b20069ca79723e`，身份参照[来源结构报告](../full_structure_v1/structure_report.json)。原文不复制进本报告。

在 implementation 目录的 PowerShell 执行：

```powershell
uv run --locked python scripts/inspect_sft_encoding.py `
  --source-report ../experiments/sft_mini_data_inspection_v1/full_structure_v1/structure_report.json `
  --samples data/processed/sft_candidate_inspection_v1/random_sample.jsonl `
  --sample-key random `
  --report-dir ../experiments/sft_mini_data_inspection_v1/encoding_preflight_v1
```

现有输出目录拒绝覆盖；复跑时将 report-dir 改为新的版本。此命令加载本地 tokenizer，核对其 JSON 文件身份及编码器、validator、脚本的代码身份。本入口核对抽样文件与关联报告，不逐行重读完整 1.74GB 原文件，因此不宣称这次重新证明了全部源行关联；此前来源核验和抽样身份验证仍由对应报告承担。

有诊断标记时仍保存报告并返回退出码 2，没有检出标记时返回 0。程序契约错误，例如编码器返回长度不一致的两列，直接中止，不将其静默当作普通坏数据跳过。

## 3. 结果与口径

| 项目 | 实际结果 |
| --- | --- |
| 样本数 | 1,000：plain 599、reasoning_only 311、tool_only 90 |
| 成功编码 | 1,000 |
| 检出的结构/转换/编码异常 | 0 |
| 潜在消息边界字面标记、shift 后零目标 | 均为 0 |
| 模板后长度 | 最短 35，最长 1,662，平均 500.121 |
| 长度分位数 | P50=499，P90=722.3，P95=779.1，P99=983.04 |
| 有效助手目标 | 总计 420,806；每条最少 9、最多 1,481 |
| 监督比例 | 420,806 / 499,121，约 84.31% |

长度包括完整模板、工具声明、历史上下文及保留的思考，不截断、不 padding。分位数使用 NumPy linear 插值，因此可能出现小数。监督比例的分母是全部样本的 `sum(max(input_length-1, 0))`，不是简单的 token 总数或各样本比例的算术平均。

本轮保留的思考、助手正文、工具调用和结束序列仍按当前工作规则监督，没有提前确定最终思考策略。90 条工具形态样本的监督比例约 25.45%，与其工具声明、用户消息及工具结果占据上下文有关；不能把较低比例直接视为质量差。

结果见 [report.json](report.json)。[records.jsonl](records.jsonl) 保存逐条来源行、原行 hash、形态、长度、目标数与诊断标记，不保存完整原文、token IDs 或训练样本副本。报告内记录明细文件的 hash，并提供最长十条的来源索引，供后续查阅。

## 4. 验证与限制

脚本的 7 项定向测试通过（10.68 秒），覆盖目标 shift 口径、统计、错误分类、样本身份、重复源行、编码契约和 CLI 产物/拒绝覆盖。测试与入口由助手按当前推进任务实现，不记为学习者独立完成。

新增入口后，全项目 `uv run --locked pytest -q` 为 402 passed（53.90 秒）。报告中记录的代码和 tokenizer 身份、逐条明细文件 hash、总输入位置及总目标数量另行重新核对一致。Git 对该脚本保持原始字节，避免跨平台换行转换使已记录的 hash 失效。

当前结果不保证回答正确、工具已声明或参数语义合理，也未证明边界检测完备。不能由 1,000 条无编码标记推断完整候选全部合格；P99 也不是最大值，不能据此断言 1,024 一定容纳全部记录。

本次未执行内容筛选、身份改写、截断、切分、训练或冻结。正式实验前，应对最终实际采用的派生数据全量执行相应预检，而不是把本次样本报告当作最终数据验收。下一步先讨论这些长度与监督量在样本中表达了什么，再决定长度处理及其他未完成规则。
