## 1. 结论与范围

从第一版派生候选的训练部分，按普通、思考、工具形态各固定抽取 8 条，共 24 条。主助手读取完整上下文并记录[逐条建议](reviews.assistant.jsonl)：9 条具体暂存、7 条仅在注明范围保留、8 条不确定事实或能力依据待核实。后两类不是全项质量通过，暂存也不推广为全量关键词规则。

样本位于 `implementation/data/processed/sft_prepared_768_v1/quality_review_sample.jsonl`，文件身份见[第一版报告](../preparation_768_v1/report.json)的 `outputs.quality_review_sample`。来源行号指向最初固定原始文件，具体执行通过输入候选 SHA256 和已核验的来源对应表绑定。第二版处理策略内联列出 9 个来源行及理由，均可从暂存数据复查。

## 2. 复核方法

1. 先检查用户实际提供了什么、要求什么，再看全部助手正文、思考与工具结果。
2. 对能独立计算的局部结论，使用自己编写的普通 Python 算术或字符串操作，不执行语料中的代码或工具。
3. 记录“局部正确但整体示范有问题”的情况；正确的最终选项不能抵消混乱解释，正确计数不能证明选择了正确输入。
4. 对医疗、危险专业活动、新闻、法律和实际图片交付等没有足够依据的内容，标记不确定，不因回答流畅就宣称正确，也不凭助手印象批量删除整个领域。
