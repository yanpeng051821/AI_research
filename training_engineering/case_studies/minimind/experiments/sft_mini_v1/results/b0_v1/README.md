## 4. 初步观察

36条都生成到256个新token，均未提前EOS。按合同，这个停止现象单独报告，不自动将36条全部判错；答题质量仍按各题检查点评分。

完整查看36条输出后，按冻结检查点初评核心题通过3条、失败29条，补充工具题失败4条，无不确定判定。instruction-01 要求只输出指定 JSON，实际反复输出“我是你的”；context-01 要求修改开会时间并保留地点，实际重复提交时间；tool-03 要求解读天气结果，实际重复 function。

三条通过都存在重复，不等于三条优质回复。尤其 grounded-01 虽答对地点，却添加错误时间；原检查点没有覆盖这项错误，因此保留V1通过标签并明确标记评分缺口，不能事后悄悄加规则。完整逐检查点证据见[评分记录](scoring_v1/reviews.assistant.jsonl)，机器汇总见[summary.json](scoring_v1/summary.json)。

这些现象表明：在本轮固定对话模板和贪心设置下，已查看输出存在明显的指令遵循、相关性和重复问题，结束行为也需要改善。不因此否定模型所有续写能力，也不预先保证 SFT 一定能修复。没有临时增加生成长度、改采样方式或换提示来美化基线。
