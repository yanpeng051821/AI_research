# 微调规模规律：案例总览

更新：2026-11-06。本轮主线阅读完成，不代表逐页读完所有附录或完成复现。

**本篇的价值：学习怎样研究模型、数据和微调方法的关系，不照搬其效果或配方。**

各环节保留“我们的思考”和“待验证问题”，作为后续阅读与实验的线索；它们不是作者结论或已验证规律。

阅读链路：[研究目标](#1-研究目标) → [评测](#2-评测标准) → [模型起点](#3-模型起点) → [数据设计](#4-数据设计) → [训练配方](#5-训练配方) → [实验结论](#6-对照实验与结论)。

## 1. 研究目标

**作者的问题：已有预训练模型的任务微调效果，怎样随模型基础、任务数据和微调方法变化？**

| 关注因素 | 要回答的问题 |
| --- | --- |
| 微调数据量 | 固定模型和方法，增加任务样本有什么收益？ |
| 模型起点 | 模型规模、此前预训练量怎样影响微调后的表现？ |
| 微调方法 | 全参数微调、Prompt Tuning、LoRA 及新增参数规模有何差异？ |
| 规律预测 | 用部分实验拟合的关系，能否预测留出设置的成绩？ |

- 作者以翻译和摘要研究这些关系，不是交付测试专用模型。
- 论文围绕微调数据量，分别与其他因素联合分析，没有遍历全部因素组合。
- **我们的思考**：先分清各因素的影响，再研究搭配；局部最佳不能直接拼成全局最佳，“最佳”必须限定任务指标与预算。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 1、3 节。

## 2. 评测标准

### 2.1 指标与数据隔离

| 评测内容 | 作者采用的口径 | 我们关心的限制 |
| --- | --- | --- |
| 参考答案预测 | 目标文本的 token-level PPL，用于规模曲线 | 不是任务准确率，不等于实际生成质量 |
| 翻译生成 | 贪心生成，用 BLEURT 评估 | 不等于测试领域的业务可用质量 |
| 摘要生成 | 贪心生成，用 ROUGE-L 评估 | 不能直接迁移为根因或修复建议的验收指标 |
| 规律预测 | 留出实验点的预测成绩与实测成绩之差 | 预测误差不是业务错误率 |

- **文本划分**：训练集更新参数，开发集选择 checkpoint，测试集报告成绩。
- **实验点划分**：部分设置参与拟合，其余设置留出；留出设置也实际训练和评测。
- 两层划分作用不同；只比较实测效果，不必额外拟合规律。

### 2.2 未微调 baseline 是否齐全？

| 实验 | 未微调基模的同口径对照 | 可以判断什么？ |
| --- | --- | --- |
| 图 1 至 4：规模曲线 | 图中未明确展示 | 比较不同微调设置，不能直接量化相对基模的收益 |
| 图 6：相关翻译方向的零样本评测 | 未清楚展示 | 比较微调后模型，不能据曲线量化微调前后损失 |
| 图 11、12：单示例、五示例评测 | 有，Baseline 列为未经微调的模型 | 比较相同示例评测方式下的微调前后表现 |

**不能说整篇论文没有基模对照，也不能用附录的少样本 baseline 补算其他评测的收益。**
**我们的思考**：模型之间的排名不能代替微调收益；必须用同一测试集、提示方式、生成配置和指标比较微调前后。

## 3. 模型起点

### 3.1 作者怎样选择模型？

| 起点 | 预训练语料 | 本次任务微调 |
| --- | --- | --- |
| En-De 双语基模 | 英语、德语单语语料混合 | 英语→德语翻译；多语言摘要 |
| En-Zh 双语基模 | 英语、中文单语语料混合 | 英语→中文翻译 |

- 作者自行预训练两组模型，规模为 **1B、2B、4B、8B、16B**；采用 decoder-only Transformer、multi-query attention 和修改后的 UL2 目标。
- 语言范围重叠不等于已训练过翻译任务；不是用 En-Zh 基模配英德翻译数据完成本文的翻译微调。
- 起点是预训练 checkpoint，没有报告中间独立的通用指令 SFT 阶段；当前的配对样本训练属于有监督任务微调。
- **SFT 与 LoRA 不互斥**：SFT 说明监督训练方式，LoRA 说明更新哪些参数。

### 3.2 对我们的意义

- 数据量对照必须从同一个 checkpoint **独立开始**，不是小子集训完再接着训大子集。
- 模型规模相同不等于起点相同；开源模型要固定 revision、tokenizer、模板及 Base/Instruct 身份。
- 不同开源模型的对比可能同时涉及架构、数据和训练履历，应解释为候选模型的整体比较。
- **我们的思考**：我们可能从已后训练的开源模型继续做垂类微调，与本文起点不同，需关注所选版本的实际能力，而不是只看参数量。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 2 节、表 1；开源模型实验要求为本轮讨论整理。

## 4. 数据设计

### 4.1 数据池与规模

| 任务 | 完整数据池 | Prompt / LoRA 子集 | 全参数微调子集 |
| --- | --- | --- | --- |
| WMT14 英德翻译 | 约 450 万条 | 8 千至 10 万条 | 10 万至 450 万条 |
| WMT19 英中翻译 | 约 2500 万条 | 8 千至 10 万条 | 100 万至 2500 万条 |
| 本文多语言摘要 MLSum | 约 110 万条 | 8 千至 10 万条 | 10 万至 90 万条 |

摘要数据组合了德语、西班牙语、法语 MLSum 与英语 CNN/Daily-Mail。各方法的子集范围不一致，不是覆盖全部相同数据量的完整方法对照。

### 4.2 我们关心的数据量定义与控制

| 名称 | 含义 |
| --- | --- |
| 数据池规模 | 可供抽样的源数据量 |
| 微调子集规模 | 本次选入的样本条数，不自动等于去重后的独立信息量 |
| 累计训练 token | 训练实际处理的 token，重复训练会增加此数 |
| 预训练量 | 微调起点此前累计处理的预训练 token，不是本次微调数据量 |

- 作者每个设置运行三次，使用不同随机训练子集，报告平均成绩。
- 多语言摘要抽样保持语言配比固定；子集是否嵌套、去重后信息量未明确说明。
- **我们的待验证问题**：固定模型逐步增加独立案例，再比较不同模型的数据量曲线；控制内容组成、隔离规则，并区分新案例收益与重复训练收益。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 2 节、表 1；数据量定义的区分为本轮讨论整理。

## 5. 训练配方

### 5.1 监督与参数更新

**输入和目标拼接，只对目标文本计算条件对数似然 loss。** 翻译监督是参考译文，摘要监督是参考摘要。

| 方法 | 更新范围 | 初始学习率 | Batch |
| --- | --- | --- | --- |
| 全参数微调 FMT | 全部模型参数 | 0.001 | 128 |
| Prompt Tuning | 输入前的可训练提示向量，基模冻结 | 0.3 | 16 |
| LoRA | 注意力和前馈层的低秩参数，基模冻结 | 0.01 | 16 |

- 优化器为 Adafactor，采用余弦学习率调度；学习率与 batch 在 1B 模型上按方法搜索。
- Soft prompt 长度指可训练向量的位置数，不是人工提示词字数；LoRA rank 也不是基模规模。
- 上表是作者的配置，不是我们开源模型微调的默认配方。

### 5.2 训练上限与最优 checkpoint

| 项目 | 作者做法 | 解释边界 |
| --- | --- | --- |
| 训练停止 | 最多 200K 步或 100 个 epoch，先到为止；英中 FMT 步数上限为 300K | 同一规则不等于相同步数、轮数或计算量 |
| 权重选择 | 使用开发集 PPL 最优 checkpoint | 不一定是最后权重，不保证过拟合消除 |
| 配方调优 | 按方法搜索初始学习率与 batch | 未明确报告为每个数据量、rank 或提示长度分别调优 |

- 作者承认小数据优化不稳定与开发集过拟合可能影响结果；未明确报告开发集早停规则或不同停止策略的对照。
- **我们的思考**：少样本多轮训练可能过拟合，应检查训练和开发表现；相同上限不一定对各数据量都合适，不能直接照搬 100 轮。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 2、4 节及附录第 15 页。

## 6. 对照实验与结论

### 6.1 数据、模型与方法的关系

| 实验 | 改变什么？ | 本轮带走的结论 |
| --- | --- | --- |
| 图 1：数据量 | 固定模型和方法，增加微调样本 | 指标总体改善，后段收益减小；没有普适最佳样本数 |
| 图 2：模型规模与数据量 | 模型规模、微调子集规模 | 所测英德 LoRA 中较大模型总体更好；不等于等成本下最优 |
| 图 3：预训练量与数据量 | 固定 1B，换不同预训练进度的 checkpoint 与微调子集 | 更多预训练量的起点总体更好；不能把任务数据视为总能补齐起点差距 |
| 图 4：新增参数与数据量 | 固定 1B，改变 LoRA rank 或 soft prompt 长度及子集规模 | 增参收益总体有限，部分设置不稳定；不是普适的最优 rank 结论 |
| 图 5：方法打平的数据量 | 从拟合关系估计相等成绩位置 | 对我们直接选型价值有限，不作为数据门槛，至此结束讨论 |

**共同边界：**

- 这里主要比较微调后的成绩，不直接等于相对原始基模的提升。
- 图 3 的中间 checkpoint 只是预训练量的代理，不是各预算分别优化的预训练结果。
- 方法配置和数据覆盖范围不同，不能把变化全部归因于一个因素，也不是完整等预算比较。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 3 至 5 节、图 1 至 5；对我们选型价值的判断为本轮讨论整理。

### 6.2 拟合规律能否用来预测？

- 作者用部分实验拟合经验关系，并用留出设置检验；它不是由模型结构推导出的必然定律。
- 16B 英中 Prompt、LoRA 的外推偏差较明显，说明预测不能无条件推广。
- 作者将失准与拟合规模档位较少、16B 英中基模表现异常联系起来；这是解释线索，不是隔离因素的因果证明。
- 图 5 的部分打平位置来自实测范围外的外推，且单看交点不能确定两边谁更好、差多少。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 3 至 5 节及附录图 10。

### 6.3 相关任务与实际使用方式是否受影响？

| 实验 | 评测方式 | 观察与结论 |
| --- | --- | --- |
| 图 6：相关翻译方向 | 英德微调后测其他语言→德语；英中微调后测其他语言→中文，推理不提供示例 | 英中 FMT 的部分较大模型随数据增加分数下降，Prompt / LoRA 较平稳；英德走势不同，影响依赖任务与方法 |
| 图 11：单示例评测 | 翻译和摘要，推理提供一个示例；有未微调 baseline | 较大模型的 Prompt / LoRA 往往接近 baseline；1B 英德的 Prompt / LoRA 可明显改善；部分 FMT 曲线退化 |
| 图 12：五示例评测 | 推理输入提供五个示例，包含未经微调的 baseline；英德与英中翻译 | 许多 FMT 设置低于 baseline，Prompt / LoRA 整体较平稳；不是所有模型、方法都保持或提升 |

- 示例是推理输入中的“原文与译文”或“文章与摘要”，不做梯度更新；不是额外训练阶段，也不是 Prompt Tuning 的可训练向量。
- 零样本指推理不提供示例，不代表预训练从未接触相关语言或任务。
- **我们的思考**：接近 baseline 主要支持“这种评测方式下没有明显退化”，不等于微调显著有效；原始模型加示例若已够用，需重新判断训练是否值得。
- 曲线下降限定于具体设置与评测方式，不能概括为“小模型越训越差”或“LoRA 保留全部能力”。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 5 节、图 6、附录图 11、12；未逐图带读图 13、14。

### 6.4 对我们后续研究留下什么？

**我们的方向：选定开源模型，用测试领域数据微调，判断相对 baseline 的真实收益，并回归业务必需能力。**

| 本篇可以借鉴 | 仍需我们自己的证据 |
| --- | --- |
| 固定起点，比较不同案例量、模型和方法 | 具体开源模型在限定测试任务上的原始能力与不足 |
| 区分案例数量、重复训练与计算预算 | 多少独立案例、什么训练方式值得投入 |
| 同时检查目标任务与相关能力 | 分类、根因、修复建议的质量及常用能力是否退化 |
| 用实测检验拟合与外推 | 业务可用门槛、实际体验及训练和部署成本 |

- 不预设微调一定改善；业务验收也需覆盖实际输入方式，以及证据不足时承认无法判断的行为。
- 不搬用本文的样本门槛、曲线系数和方法排名。作者也承认其证据主要来自翻译、摘要等任务，其他微调场景仍需验证。
- 以上是研究方向，不是已冻结的实验计划；阅读结束不自动启动训练，下一步见[案例入口](README.md)。

来源：[论文](sources/When-Scaling-Meets-LLM-Finetuning-2402.17193v1.pdf)，第 7 节；团队研究方向与验收要求为本轮讨论共识。
