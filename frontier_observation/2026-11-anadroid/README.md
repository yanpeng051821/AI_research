# AnaDroid：测试失败分析专用模型

首次记录：2026-11-02。更新：2026-11-05。标签：记录。状态：本轮案例阅读完成，未进行原实验复现。

## 为什么选择这个案例

论文题目为 *Automated Classification, Root Cause Analysis, and Repair Recommendations
for Failed Mobile Testing by Specialized LLM*，提出 AnaDroid，面向移动测试失败的
分类、根因分析与修复建议。论文主题贴近测试团队建设专用模型的方向。

我们的学习目标是：面对真实测试问题，能够定义目标、组织数据、选择模型与训练方法、
设计评测，并形成可执行的完整链路。训练模型是项目产物，决策与验证能力是团队需要
积累的经验。团队具体任务、数据条件与验收标准仍需后续明确。

其他案例补充。数据因素归因是其中一个问题，不作为唯一选材方向。
