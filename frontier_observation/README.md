## 单案例目录约定

```text
YYYY-MM-case-name/
├── README.md                 # 研究目的、当前位置、下一步、资料和文档索引
├── 01_CASE_OVERVIEW.md       # 讨论全貌时增加：问题、完整链路和结果概括
├── 02_*.md                   # 深入主题时增加：数据、模型、训练或关键实验
└── ...
```

每个正式研究的案例建立独立目录；候选不批量建目录。上面是逐步形成的结构，
不是开始前必须写好的模板；章节根据讨论需要增加，QA 放回相关主题，不单独堆成碎片。
目录日期表示开始记录的时间，不是论文发表时间。已有案例不为统一模板而批量改名。

新增材料时遵守以下边界：

1. 官方声称、仓库中已核验事实和我们的推断分开记录。
2. 优先使用论文、官方技术报告、官方模型卡、官方仓库和可追溯运行材料。
3. 每个案例必须说明它是否改变当前训练主线。
4. 只有形成明确假设、固定对照、可信指标和成本预算后，才升级为实验。
