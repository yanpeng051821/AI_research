## 单案例目录约定

```text
YYYY-MM-case-name/
├── README.md                 # 状态、研究问题、结论标签和文档索引
├── 01_CASE_OVERVIEW.md       # 已核验事实、证据边界和路线关系
├── 02_*.md                   # 后续专题，例如架构、数据或训练链路
└── ...
```

新增材料时遵守以下边界：

1. 官方声称、仓库中已核验事实和我们的推断分开记录。
2. 优先使用论文、官方技术报告、官方模型卡、官方仓库和可追溯运行材料。
3. 每个案例必须说明它是否改变当前训练主线。
4. 只有形成明确假设、固定对照、可信指标和成本预算后，才升级为实验。
