# 模型基础：从预测任务到可训练网络

> 以语言模型为入口，理解神经网络如何组织计算、形成表示并通过训练改变行为。
> 更新：2026-10-02。本文是知识导航，不改变 MiniMind 实践顺序。

## 主线

“知道每个模块怎么算”与“理解整个模型为什么这样组织”之间，还缺一层连接：
**任务提出需求，架构组织信息，loss 提供学习信号，梯度与优化器改变参数。**

阅读时始终带着同一个问题：模型看见“我喜欢”后，怎样为下一个 token 分配概率？
它先把编号变成向量，再让各位置交换信息、加工特征，最后产生词表分数。
训练并不是逐层告诉它“某个神经元应表示喜欢”，而是从预测误差反向调整共同参与计算的参数。

```text
任务与数据 -> token ID -> Embedding -> 上下文交流与特征加工
           -> logits -> loss -> backward -> 参数更新
```

这是阅读地图，不是说先运行模型、再临时决定训练目标。数据、模型、目标与评测需要提前协同确定。

## 层次

每个模块都从四个层次理解：

1. 功能：为什么需要它，输入与输出承担什么角色。
2. 机制：公式、小数值和张量形状怎样对应。
3. 学习：参数在哪里，梯度经过哪里，哪些行为由数据学出来。
4. 证据：测试为什么需要，验证了什么，又不能证明什么。

当前重点是解释现有模型，而不是增加组件改造或消融作业。
“检验”用于理解已有测试的理由；“复习”提供核对思路，不要求背答案。
正文 Python 代码块都是可独立运行的小实验；结构示意使用 text，不冒充完整实现。

示例已在 Python 3.12.13、PyTorch 2.14.0 的 CPU 环境运行验证，不需要下载模型权重或租用 GPU。
可以在 MiniMind 的 implementation 环境中用 `uv run python` 复练，
也可以使用已经安装 PyTorch 的独立 Python 环境。运行成功用于核对局部机制，不代替真实训练验收。

## 约定

B 是 batch 大小，T 是序列长度，V 是词表大小，D 是隐藏维度，H 是前馈中间维度。
隐藏状态通常写为 X，形状 [B,T,D]；单个向量使用小写 x。
列向量公式写 Wx，PyTorch 批量计算写 X @ W.T，二者关系在第 02 篇推导。

“特征”是内部计算使用的数值维度或组合，不预设每一维对应一个人类词义。
“学习”是参数受到数据和目标影响而改变，不意味着模块名称直接等于它学到的语义。

## 理解标准

能够跟踪一个 token 的表示变化，说明每一层收到什么、处理什么、交出什么，
并沿 loss 反向解释哪些参数为什么得到梯度。
这比单独记住每个公式更接近独立理解模型所需的基础。

理解已有架构、独立搭建可工作的模型、提出新的有效架构是不同层次。
本系列先建立机制理解，不把测试通过或阅读完成等同于掌握所有神经网络。
