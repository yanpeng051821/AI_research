# 向量、矩阵与线性层

> 向量承载一个对象的数值表示，线性层用可训练的权重重新组合这些特征。
> batch 与序列维告诉我们“在处理哪些对象”，特征维告诉我们“每个对象怎样被表示”。

[系列导航](README.md) · 前篇：[自回归](01_AUTOREGRESSIVE_LANGUAGE_MODELING.md) · 后篇：[激活](03_LINEARITY_NONLINEARITY_AND_ACTIVATIONS.md)

## 表示

一个 token 被表示为 \(x=[x_1,x_2,x_3]\)，首先只是说：网络用三个数共同描述它。
这些数不是一定能逐项命名的“情绪、时间、主语”。训练中形成的意义往往分布在多个维度及其组合中。

向量有两个互补视角。几何上，它是坐标空间中的一个点或位移，可以讨论方向、长度、夹角；
计算上，它是一组待组合的特征值。几何视角帮助理解变换，特征视角帮助追踪模型的信息处理。
二者不是两种不同的数据。

“列向量”与“行向量”则是书写和存储约定，不是在说箭头朝上或朝右。
\([1,2,3]^T\) 与写成一行的同一组坐标，都可描述同一个特征向量，但矩阵乘法的排列必须相容。

## 组合

### 点积

两个向量的点积是对应分量乘积之和：

\[
w\cdot x=\sum_jw_jx_j
\]

若 \(x=[1,2,3]\)，\(w=[1,2,0]\)，则结果是 \(1+4+0=5\)。
把 w 当成参数时，它规定每个输入分量如何贡献给这个输出。
负权重可以抵消，零权重暂时不使用该分量，但不意味着某个维度永远无用。

几何上，点积也等于 \(\|w\|\|x\|\cos\theta\)。
它同时受方向和长度影响，因此“点积大”不等于“语义一定更相似”，更不等于余弦相似度。
后续 Attention 会用学习后的 query/key 点积产生匹配分数，但分数的意义仍来自整个训练目标。

### 多个输出

如果想从三个输入特征得到两个输出特征，就使用两组权重：

\[
W=\begin{bmatrix}1&2&0\\0&1&3\end{bmatrix},
\quad b=\begin{bmatrix}1\\-1\end{bmatrix},
\quad y=Wx+b
\]

第一行提取 \(x_1+2x_2\)，第二行提取 \(x_2+3x_3\)，再各加一个偏置。
对 \(x=[1,2,3]^T\)，输出是 \([6,10]^T\)。

这里的“提取”不是发现一个预先指定的语义标签，而是产生一组新的可学习组合。
下一层可以继续组合这些输出，使表示逐步适合最终预测。

常说的一个人工“神经元”，可以理解为一组加权求和、偏置以及接在后面的激活；
多个这样的计算并排构成一层，多层再按一定连接方式组成网络。
在 PyTorch 中，Linear 和激活通常是分开的操作，所以一个模块对象不一定对应教科书里的完整“神经元”。
这是一种数学计算单元，不应直接等同于生物神经元或一个独立的人类概念。

### 几何变换

从列的角度看：

\[
Wx=x_1W_{:,1}+x_2W_{:,2}+\cdots+x_DW_{:,D}
\]

即输入坐标决定如何组合 W 的各列。每一列也是对应单位基向量经过变换后的结果。
例如 \(A=\left[\begin{smallmatrix}2&1\\0&3\end{smallmatrix}\right]\)，输入 \([3,2]^T\)：
第一条基方向变成 \([2,0]^T\)，第二条变成 \([1,3]^T\)，输出为
\(3[2,0]^T+2[1,3]^T=[8,6]^T\)。

按行看是“每个输出如何读取全部输入”，按列看是“每个输入如何影响全部输出”。
它们是同一个矩阵乘法，不必在两种解释之间选一个。
可结合[线性变换的几何演示](https://www.3blue1brown.com/lessons/linear-transformations)观察；
模型里的权重不一定对应容易命名的旋转或缩放。

## 批量计算

数学推导通常把一个输入写成列向量，PyTorch 常把多个输入按行存储：

\[
X=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix},
\qquad Y=XW^T+b
\]

W 的 shape 是 [D_out,D_in]；X 是 [N,D_in]。
转置不是一个额外的学习步骤，而是让每条输入都与 W 的每一行做点积。

两种写法相容，因为 \((Wx)^T=x^TW^T\)。
多个样本一起计算只是把这条关系并排执行：

```python
import torch
from torch import nn

x = torch.tensor([[1., 2., 3.], [4., 5., 6.]])
w = torch.tensor([[1., 2., 0.], [0., 1., 3.]])
b = torch.tensor([1., -1.])
layer = nn.Linear(3, 2)
with torch.no_grad():
    layer.weight.copy_(w)
    layer.bias.copy_(b)
manual = x @ w.T + b
torch.testing.assert_close(manual, torch.tensor([[6., 10.], [15., 22.]]))
torch.testing.assert_close(layer(x), manual)
```

偏置 [2] 广播给每行，不是每个样本拥有一套独立偏置。
这里的参数共有 \(3\times2+2=8\) 个，不会因为 batch 增大而增加。
[PyTorch Linear 的参数和输入约定](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Linear.html)

## 维度

### 特征轴

语言模型的隐藏状态常为 [B,T,D]。例如 [2,4,3] 表示两条序列，每条四个位置，每个位置三个特征。
对它使用 Linear(3,5)，输出为 [2,4,5]：

\[
Y_{b,t,k}=\sum_{j=1}^{D}W_{k,j}X_{b,t,j}+b_k
\]

求和只发生在 j 上，b 和 t 没有被求和，所以每个位置独立使用同一 W。
实现可以使用高效批量内核，不是真的需要 Python 三重循环。

这解释了“好像都在处理最后一维”的观察，但它不是所有神经网络操作的普遍规则：
Linear 在这里组合特征，RMSNorm 对特征轴计算统计量；Attention 则会在序列位置之间加权汇总。
判断操作什么维度，应看公式或 API，不是看张量恰好有几维。

### 轴与数值

`mean(dim=-1)` 沿特征求平均。保留维度后 [B,T,D] 变成 [B,T,1]，
便能广播回每个位置的 D 个特征。若误用 dim=1，就变成沿时间位置统计，含义完全改变。

`reshape` 主要重新组织元素到新的形状；`transpose` 交换轴。
不能因为元素总数一样，就认为二者可以互换。把 [B,T,D] 分成 [B,T,h,d]，
再转为 [B,h,T,d]，分别是在拆分特征和交换轴，后者不是再做一次简单 reshape。
Attention 的多头实现会依赖这个区别。

### 两种乘法

`@` 是矩阵乘法，会对相接的维度求和；`*` 通常是逐元素乘法，可应用广播。
SwiGLU 两个 [B,T,H] 分支用 `*` 对应通道相乘，不是把它们做矩阵乘法。
后续 Q @ K.T 产生位置间分数，又属于另一种信息组织。

## 宽度

线性层可以升维，例如 D=2 到 H=8。它增加了可供后续使用的组合数量，
但不能凭空得到原输入没有的信息。
没有非线性时，8维输出仍受最多2个独立输入方向约束，其线性映射秩不超过2。

为什么网络仍经常升维？因为后面会对不同组合应用非线性，让它们表现出不同响应，
再重新组合。宽度提供更多中间计算通道，非线性使这些通道不只是线性冗余。
它们共同增强函数表达能力，而不是“维度更高，所以自动多出知识”。

降维则把多个通道汇总到较少通道。它可能丢弃信息，也可以学习保留对任务有用的组合。
FFN 降回 D 还有结构原因：输出必须能与残差主路径同形状相加。详见[第 06 篇](06_FEEDFORWARD_AND_SWIGLU.md)。

## 学习

线性层的权重不是输入数据的复制，它是跨样本复用的参数。
用列向量形式 \(y=Wx+b\)，若上游传回 \(g=\partial L/\partial y\)，则：

\[
\frac{\partial L}{\partial x}=W^Tg,\qquad
\frac{\partial L}{\partial W}=gx^T,\qquad
\frac{\partial L}{\partial b}=g
\]

第一式将学习信号传给前一层；第二式说明权重梯度同时依赖当前输入和输出处的学习信号。
多个位置共用同一个 W，因此各位置的贡献累加到它的梯度中。
梯度不是仅由权重大小决定，也不是“使用次数”本身。

从这里可以看到两个方向：前向将特征投影到新空间，反向通过同一计算关系传递误差信号。
是否保存中间张量的 .grad 是框架层面的另一件事，不影响导数存在。

## 检验

验证 Linear 不能只看 shape，因为错误的权重排列有时也能得到同样 shape。
小而不对称的 W 可以暴露转置错误，非零 b 可以暴露漏加偏置；
[B,T,D] 输入可以检查前导维是否保留。

将“相同输入出现在两个位置”作为对照，可以观察参数共享：
在这个 Linear 单层中两处输出应相同。它不说明完整模型输出也相同，因为后续上下文会不同。

`assert` 适合布尔条件，如 shape 相等；张量浮点结果应使用 `torch.testing.assert_close`：
它按容差比较每个元素并提供误差定位。浮点运算顺序改变可能造成微小舍入差，
因此直接要求逐位完全相等通常不是数值测试的目标。

## 复习

**为什么转置 W？** 存储的每一行是一个输出通道的输入权重；行式 batch 通过 X @ W.T 与这些行逐一做点积。

**为什么 batch 长度变化不会改变 Linear 参数？** 权重绑定特征维，不绑定 B 或 T。
需要匹配的是最后一维 D，内存和运行时间仍会随 B、T 改变。

**为什么线性升维不等于增加独立信息？** 输出是原输入的确定性组合，秩受输入维度限制。
后续激活的价值是改变函数的表达形式，而不是注入新的外部信息。
